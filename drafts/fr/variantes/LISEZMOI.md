APRES que j aie deja copie sa version precedente dans `content/`.

Pourquoi la version publiee n est pas celle-ci: les agents ont raccourci leur
texte d environ 7 % pour tenir dans la cible de 1 200 a 1 800 mots que je leur
avais donnee. Les deux versions disent la meme chose et passent les memes
controles. La version publiee est simplement la plus fournie, et c est elle qui
a servi de source aux traductions en cours au moment ou la question s est posee.

Rien n est perdu: si vous preferez la version courte pour l un de ces trois
articles, elle est ici, prete a remplacer celle de `content/fr/articles/`.
La date et le champ lastmod devront alors etre repris du fichier remplace.
