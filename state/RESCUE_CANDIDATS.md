# Sujets repeches du catalogue de reference

Contexte. Le catalogue de reference comptait 619 titres. 158 ont ete retenus dans
`state/content_plan.json`. 461 avaient ete ecartes comme decoration, jardinage,
voyage, recettes, idees-cadeaux ou activites familiales: sans valeur pour un
courtier immobilier.

J ai relu les 461 titres un par un avec un filtre plus large: **un sujet est
repechable seulement s il peut etre ancre sur une regle quebecoise verifiable,
un permis, un cout reel, une regle d assurance, une loi ou une donnee de marche.**

Voici les titres qui passent ce filtre, regroupes quand plusieurs titres de
reference traitent du meme angle. Le titre de reference ne sert QUE d indication
de sujet: il ne faut jamais reprendre son plan ni ses formulations.

Plusieurs candidats risquent de recouper un article deja publie. C est la porte 1
qui tranche, pas l intuition.
