# Couleurs RE/MAX DU CARTIER

Rappel. La reference du projet est `../../../CHARTE-COULEURS.md`, et la regle 3
de `../../../CLAUDE.md` la rend obligatoire pour tout visuel fabrique ici.

| Couleur | Hex | RGB | Rang |
|---------|-----|-----|------|
| Navy | `#000E35` | `(0, 14, 53)` | **principale** |
| Creme | `#F7F5EE` | `(247, 245, 238)` | **principale** |
| Bleu | `#0043FF` | `(0, 67, 255)` | secondaire |
| Bordeaux | `#600000` | `(96, 0, 0)` | secondaire |
| Rouge | `#FF1200` | `(255, 18, 0)` | secondaire |

Trois regles qui vont avec:

1. Les grands aplats sont navy et creme. Les secondaires accentuent: un filet,
   une pastille, un mot, un bandeau.
2. Le texte sur fond sombre est creme `#F7F5EE`, jamais blanc pur.
3. Aucune teinte choisie a l oeil. Si une couleur manque, elle se decide dans
   la charte d abord, pas dans le fichier qu on est en train d ecrire.

Polices: Playfair Display pour les titres, Inter pour le reste.

Les ecarts connus entre ce rappel et les constantes de certains generateurs
sont listes dans la charte, section "Ou les couleurs vivent dans le code".
