Comment fonctionne le calcul ?
ABD Amortissement Brut de la Dette Coûts de logement (hypothèque + taxes + chauffage) ÷ revenu brut. Limite : 39 %
ATD Amortissement Total de la Dette ABD + toutes vos autres dettes mensuelles ÷ revenu brut. Limite : 44 %
Test de résistance Le calcul utilise le plus élevé entre : taux contractuel + 2 % ou 5,25 %. Cela simule une hausse de taux pour s'assurer que vous pouvez toujours payer.
{{ else if $isAr }}
كيف يعمل الحساب؟
GDS نسبة تكاليف السكن الإجمالية تكاليف السكن (قسط الرهن + الضرائب + التدفئة) ÷ الدخل الإجمالي. الحد الأقصى: 39%
TDS نسبة إجمالي الديون GDS + جميع ديونك الشهرية الأخرى ÷ الدخل الإجمالي. الحد الأقصى: 44%
اختبار الإجهاد يستخدم الحساب الأعلى من: المعدل التعاقدي + 2% أو 5.25%. يحاكي ارتفاع المعدلات للتأكد من قدرتك على الدفع.
{{ else if $isEs }}
¿Cómo funciona el cálculo?
GDS Servicio de deuda bruta Costos de vivienda (hipoteca + impuestos + calefacción) ÷ ingreso bruto. Límite: 39%
TDS Servicio de deuda total GDS + todas sus otras deudas mensuales ÷ ingreso bruto. Límite: 44%
Prueba de estrés El cálculo usa el mayor entre: tasa contractual + 2% o 5.25%. Simula un aumento de tasa para garantizar que pueda seguir pagando.
{{ else }}
How does the calculation work?
GDS Gross Debt Service ratio Housing costs (mortgage + taxes + heating) ÷ gross income. Limit: 39%
TDS Total Debt Service ratio GDS + all your other monthly debts ÷ gross income. Limit: 44%
Stress test The calculation uses whichever is higher: contract rate + 2% or 5.25%. This simulates a rate increase to ensure you can still afford payments.
